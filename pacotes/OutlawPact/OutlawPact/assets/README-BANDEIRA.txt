BANDEIRA PERSONALIZADA — OUTLAW PACT ALPHA 0.2

Coloque sua imagem nesta pasta com o nome flag.png.
O caminho no jogo é:
D:\Program Files (x86)\Steam\steamapps\common\Red Dead Redemption 2\OutlawPact\assets\flag.png

Use PNG de até 4096 x 4096 pixels. Uma imagem horizontal na proporção 3:2 funciona melhor.
Logotipos simples, com cores fortes, ficam mais legíveis.

Depois, reconstrua o acampamento pelo F7 para recarregar a imagem.

Esta primeira bandeira é um painel em pixels, desenhado no mundo em 24 x 16 pontos.
Ainda não é uma textura HD em tecido animado. Se não houver imagem válida, aparece o desenho padrão preto e dourado.

Seu arquivo não será substituído pelo instalador.
